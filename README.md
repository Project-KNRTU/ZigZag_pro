# ZigZag_pro

Мини‑приложение в MAX для планирования маршрута по городу (достопримечательности, ТЦ, кафе и т.д.) с учётом компании, времени, интересов и транспорта.

## Назначение

Помощь жителям и туристам в поиске подходящих культурных, спортивных и развлекательных мест и построении оптимального пути между ними.  

## Основной пользовательский сценарий

1. Пользователь открывает чат‑бот ZigZag_pro в мессенджере MAX.
2. Нажимает кнопку «Построить маршрут» → открывается Mini App.
3. В Mini App выбирает:
   - компания ,
   - временной диапазон ,
   - интересы ,
   - тип транспорта.
4. Система формирует оптимальный маршрут и показывает интерактивную карту с путём и точками посещения.
5. Пользователь видит описание маршрута и может сохранить его / поделиться.

## Состав и архитектура решения

- **Frontend (Mini App):** HTML, CSS, JavaScript.
- **MAX Bridge:** взаимодействие с мессенджером MAX.
- **Карта:** Яндекс.Карты JS API (или 2GIS/OSRM) для отображения маршрута.
- **Данные:** локальные JSON‑файлы с тестовыми местами и маршрутами (MVP).


## Данные

В MVP используются тестовые, заранее подготовленные данные о местах и маршрутах. Реальное расписание автобусов и точная маршрутизация симулированы.

## Ограничения MVP

- Маршрутизация упрощённая (жадный алгоритм, без точного расписания транспорта).
- Пока реализован один город (можно расширить).
- Нет полноценного бэкенда (вся логика на фронтенде).
